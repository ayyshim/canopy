## writing.copy
- Say what the product does and why it matters in the first line.
- One message per piece, one clear action to take.
- Use the reader's own words; cut hype and empty claims.
- Give two or three headline options when asked for copy.
- Keep to the brand's voice and any length limit.

## writing.technical
- Write for someone doing a task: steps in order, one action per step.
- Try the steps yourself or run the commands so they are known to work.
- Show real examples, inputs and outputs, and the common errors.
- Define a term the first time you use it.
- Put the file where the other docs live and link to it.

## writing.editing
- Read once for the big picture: order, gaps and the main point.
- Then edit for clarity, tone, grammar and repeated words.
- Keep the author's voice; change only what helps the reader.
- Don't change facts without checking them.
- Return the edited text with a short list of the main changes.

## writing.blog
- Pick one idea and a working headline that promises it.
- Open with a reason to keep reading, not background.
- Support points with examples, numbers or short stories.
- Keep paragraphs short and add subheads for scanning.
- Check facts and links, and end with a clear next step.

## writing.translation
- Translate meaning and tone, not word by word.
- Keep names, numbers, dates and formatting correct for the target region.
- Leave product names, code and placeholders untouched.
- Use one term for each idea throughout.
- Flag unclear source text instead of guessing, and ask a person who speaks the language to check key pieces.

## writing.creative
- Know the point of view, the character's want and what stands in the way.
- Show through action and detail instead of explaining feelings.
- Keep a consistent voice and tense.
- Read dialogue out loud; cut lines nobody would say.
- Ask a person about tone, length and what is off limits.

## writing.speech
- Write for the ear: short sentences, plain words, some repetition.
- Open strong and end with the one thing the audience should remember.
- Read it aloud and time it against the slot given.
- Mark pauses, emphasis and any slide or visual cues.
- Deliver a clean script plus a one-page version of key points.
